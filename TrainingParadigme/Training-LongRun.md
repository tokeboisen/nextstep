# Long run – definition

**Denne fil er den gældende definition af long run i alle programmer.**

**Type:** Long run

## Formål
- Aerob basis: kapillarisering, fedtforbrænding og udholdenhed under LT1
- Gradvis opbygning af volumen og tolerance for tid på benene
- Afsluttende strides holder løbeøkonomi og fart vedlige uden laktat

## Anvendelse
- Long run er en pastype til **long run-dagen** i ugestrukturen (Athlete.md)
- Ikke et kvalitetspas, men ugens største enkeltbelastning; dagen efter er rolig (ikke back-to-back, se Training-paradigme.md)
- Ingen opvarmning ud over de første rolige km; ingen særskilt nedløb

## Intensitetsniveauer
| Del | Pace | Puls | Bruges |
|---|---|---|---|
| Hovedløb | Vejledende fra easy/long-zonen | Easy/long-zonen, altid under LT1 | Hele distancen |
| Strides | Hurtigt og afslappet, ikke sprint | Styres ikke | 20″ pr. stride |
| Pause mellem strides | Gang/let jog | Restitutionszonen | 1′ |

Puls styrer, ikke pace. Konkrete værdier står i Athlete-zones.md. Revideres LT-værdierne der, forskydes niveauerne tilsvarende.

## Standardformat
- **X km i easy/long-zonen + 4 × 20″ strides**
- Eksempel: 10 km @5:30–5:50, puls 135–145 + 4×20″ strides (værdier fra Athlete-zones.md pr. 2026-09-28)
- Distancen fastlægges i programmet ud fra ugevolumen og seneste long run

## Varianter
| Variant | Indhold | Bruges |
|---|---|---|
| Standard | X km + 4 × 20″ strides | Normal uge |
| Kort | ~75 % af seneste long run + 4 × 20″ strides | Deload / efter pause |
| Uden strides | X km | Træthed, ømhed eller dagen efter et hårdt pas |

## Dosering
- Long run øges med højst ~1 km pr. uge og holdes under ~2 timer (se Training-paradigme.md)
- Long run udgør typisk 25–35 % af ugevolumen i genopbygning
- Deload hver 3.–4. uge med kort variant

## Styring
- Pulsen styrer, ikke pacen. Puls over easy/long-zonen i længere perioder er gråzone – sæt farten ned, også hvis pacen bliver langsom
- Varme, stærk vind eller kuperet rute: løb på puls, ikke pace
- Strides skal føles lette og hurtige – ikke udmattende
- Drik og spis som vanligt; ingen gel nødvendig under 90 min

## Vurdering af data
- Cardiac drift: stiger pulsen mere end ~5 % i anden halvdel ved samme pace, er distancen i overkanten lige nu
- Andel af tiden i easy/long-zonen; tid i gråzonen bør være lav
- Samme distance ved lavere puls over flere uger = fremgang i aerob basis
- Stigende puls ved samme pace uge over uge = tegn på træthed → følg træthedsreglerne (morgenløb skæres først)

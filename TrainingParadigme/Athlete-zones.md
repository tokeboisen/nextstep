# Athlete zones – LT-zoner, puls og pace

**Denne fil indeholder atletens konkrete zoner.** Definitionsfilerne (Training-Pyramid.md, Training-20x400.md, Training-Tempo.md, Training-10-20-30.md, Training-LongRun.md, Training-EasyRun.md) angiver niveauer relativt til LT-pace og LT-puls; tallene står her. Værdier pr. programstart 2026-09-28. Revideres LT-værdierne, opdateres denne fil.

## Grundværdier

| Parameter | Værdi |
|---|---|
| LT-pace (LT2) | 4:29/km |
| LT-puls (LT2) | 169 |
| LT1-puls | 150–155 |
| Maxpuls | 189 |

## Zoner

| Zone | Puls | % af LT-puls | Pace | Bruges til |
|---|---|---|---|---|
| Restitution | <130 | <77 % | 6:15+ | Morgenløb, jog-pauser, start på opvarmning |
| Easy / long | 130–145 | 77–86 % | 5:30–6:00 | Rolige løb, long run, søndagsvolumen |
| Gråzone | 146–149 | 86–88 % | – | Undgås i længere perioder på long runs |
| LT1-loft | 150–155 | 89–92 % | ikke målt | Øvre grænse for aerobt arbejde – long runs holdes under |
| Gråzone (steady) | 156–158 | 92–93 % | – | Ikke en målzone |
| Sub-threshold | 159–164 | 94–97 % | 4:40–4:45 | Genopbygning, første uger af en blok, efter pause/sygdom |
| Threshold | 162–169 | 96–100 % | 4:30–4:40 | Standard threshold-pas (5′ og 8′) |
| Korte threshold-stykker (2′) | når ikke LT-puls | – | 4:20–4:25 | 2′-stykker i pyramiden |
| Over LT2 | >169 | >100 % | <4:20 | Intervaller (200/300 m, 10-20-30) – styres på pace, ikke puls |

## Styringsregler

- **Easy/long:** puls styrer. Over 145 i længere perioder = gråzone → sæt farten ned.
- **Threshold:** pace styrer, puls kontrollerer. Pulsen må først nå 169 i slutningen af 8′; når den 169 før minut 6 → +5″/km resten af passet (se Training-Pyramid.md).
- **Varme, vind, bakker:** løb på puls, ikke pace.
- **Intervaller over LT2:** pace fra det aktuelle program (200 m/300 m); pulsen halter bagud og bruges ikke til styring.

## Revision

- LT-værdierne revideres, når threshold-pas viser samme pace ved 3–5 slag lavere puls i 2 pas i træk, eller når en test giver nye data.
- LT1-pace er ikke målt. Den kan estimeres fra long runs med stabil puls på 150–155 og lav decoupling (<5 %).
